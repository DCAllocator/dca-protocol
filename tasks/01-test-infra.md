# 01 — test-infra: gates, ABI sync, worktree recipe, size guard, e2e harness

## Summary
Cross-cutting prerequisite. Records the per-layer gate commands, lands an overdue ABI regeneration (committed ABIs lag
the contracts by two commits and still export a removed event), defines the per-worktree recipe (isolated pnpm store,
submodules, gitignored env/deployment files, private anvil ports), adds a hard EIP-170 size guard (vaults are 83–128 B
under the limit), and seeds the manual browser e2e checklist. Covers list items: none directly; it is what 1–7 are
verified with, and its ABI-sync commit is the branch base for every worktree.

## Proposed approach
1. Owner decides the uncommitted tree (overview Step 0). Baseline commit(s) on `main`: FeeReceiver set; latency proxy +
   scripts; Splash/site-v2; research suite. Worktrees branch from the result, never from 5ec278c.
2. **ABI-sync commit on `main`** before any frontend worktree branches: `cd contracts && forge build`,
   `pnpm --filter @dca/web abi`, `pnpm --filter @dca/scheduler abi`; fix `scheduler.ts:282` (retarget the skip branch to
   the retry-not-skip surface — `PlanTooLarge` if it carries the reason bytes `describeSkipReason` expects, else delete
   the branch) and `useLogs.ts:15-17,98` (drop or retarget `epochPageSkippedEvent`); both typechecks green. Alternative
   (fold into 03-P2) rejected: every frontend branch imports `PlanVaultAbi` and would rebase onto a 46 KB generated diff twice.
3. `scripts/abi-check.mjs` + root `pnpm abi:check`: parse each `apps/*/src/abi/*.ts` literal, compare `type:name(inputs)`
   sets against `contracts/out/<C>.sol/<C>.json`, exit 1 on diff.
4. `contracts/test/unit/ContractSizes.t.sol`: `assertLt(address(v).code.length, 24_576)` for daily/weekly/monthly/TestVault
   from the `BaseTest` fixture (`contracts/test/BaseTest.sol:96-101`); 04 adds HourlyVault.
5. `.github/workflows/ci.yml` (if approved): checkout with submodules, foundry-toolchain, `forge build --sizes`,
   `forge test`, `pnpm install --frozen-lockfile`, `pnpm abi:check`, both typechecks. Optional `FOUNDRY_PROFILE=ci` job.
6. Worktree recipe (summarised in the overview; keep the canonical text here): `git worktree add ../DCA-<slug> -b <slug>
   <abi-sync-commit>`; `git submodule update --init --recursive` (gitlinks resolve locally [hypothesis]);
   `pnpm install --frozen-lockfile` (root `node_modules` holds only `.pnpm/`, nothing hoisted); frontend-only: copy
   `apps/web/.env.local`, `apps/scheduler/.env.local`, `contracts/deployments/31337.json` from main; contract work:
   `PORT=<free 854x> TEST_EPOCH_MINUTES=1 pnpm fork` (writes only that worktree's three files — `scripts/fork.sh:20`
   resolves ROOT from its own location, `:36-40` refuses a busy port); `cd contracts && forge build` (record the cold
   via_ir build time on first use). Dev server: `pnpm exec next dev -p <free 300x>` from the worktree's `apps/web`
   (Bash-started; the preview launcher cannot cwd under `~/Documents` — attach by URL). Rules as in the overview.
7. `tasks/e2e-checklist.md` (seed below) — one section per user-facing workstream; each fills the Observed column before done.
8. Docs riding on the ABI-sync commit: `README.md:286-287`, `AUDIT.md:41`, memory note → "≤ 128 B; every PlanVault
   addition goes into a linked library". Optional: `PerPlan.Fork.t.sol` early-return → `vm.skip(true)`.

- AC6 (if CI approved) `ci.yml` is green on `main`.
- AC7 A fresh worktree reaches AC1–AC3 with exactly the documented recipe; the cold `forge build` duration is recorded here.
- AC8 After all workstreams, `lsof -nP -iTCP:8545 -sTCP:LISTEN` still shows the user's anvil and main's `31337.json` is unchanged unless the user re-ran `pnpm fork`.
- AC9 `PORT=<n> pnpm fork` inside a worktree changes nothing under the main checkout (`git -C <main> status`).
- AC10 No merged branch diffs `next-env.d.ts`/`tsconfig.json` unless deliberate and described.
